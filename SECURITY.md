# Security

## Security model

A selected snippet may be pasted into a shell, but it must never be executed automatically.

The local helper validates the selected text and the destination tmux pane before pasting anything.

## Paste helper protections

`navi-safe-paste`:

- requires an explicit tmux pane ID,
- verifies the target pane still exists,
- rejects empty selections,
- rejects newline and carriage-return characters,
- rejects terminal control characters,
- rejects unexpectedly large selections,
- uses `printf` without a trailing newline,
- uses a temporary named tmux buffer,
- deletes the buffer after paste,
- never uses `eval`,
- never executes the selected snippet through a shell,
- never sends `Enter`.

## Secrets

Do not store secrets in cheatsheets.

Examples:

- passwords
- API keys
- bearer tokens
- private keys
- database credentials
- Redis credentials
- kubeconfig client secrets
- cloud credentials

Use environment variables or your normal secret-management workflow instead.

## Navi dynamic variables

Navi cheatsheets can contain dynamic variables whose values are generated by shell commands.

Treat constructs such as dynamic `$ variable: command` definitions as executable code. Review them before adding or importing a cheatsheet.

The paste helper protects the final selected command from automatic execution, but it cannot make an untrusted cheatsheet safe if that cheatsheet itself runs code while generating dynamic values.

## Third-party cheatsheets

Treat imported cheatsheets as code.

Do not import unknown repositories blindly. Review the content first.

## SSH hardening

`scripts/harden_ssh.sh` intentionally:

- does not delete unrelated files from `/etc/ssh/sshd_config.d`,
- does not edit vendor systemd units under `/lib/systemd` or `/usr/lib/systemd`,
- validates the effective SSH configuration,
- keeps the existing TCP/22 firewall rule until the operator verifies a successful login on the new port.

This reduces lockout risk but cannot eliminate it. Out-of-band access is recommended for critical systems.
